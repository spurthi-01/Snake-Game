# Snake Game in Python
A classic Snake Game developed using Python's Turtle graphics and the FreeGames library. The player controls the snake using the arrow keys to collect food, increase the score, and grow in length while avoiding collisions with the walls or the snake's own body.

## ✨ Features

Smooth snake movement using keyboard controls.
Random food generation at different locations.
Real-time score display.
Snake grows after eating food.
Collision detection with walls and the snake itself.
Game Over message with the final snake length.

## 🛠️ Technologies Used

Python
Turtle Graphics
FreeGames Library
Random Module

## 🎮 How to Play

Run the Python program.
Control the snake using the Arrow Keys.
Eat the green food to increase your score and snake length.
Avoid hitting the walls or the snake's own body.
The game ends when a collision occurs.
This project demonstrates fundamental programming concepts such as loops, functions, lists, event handling, collision detection, object movement, and basic game development using Python.
